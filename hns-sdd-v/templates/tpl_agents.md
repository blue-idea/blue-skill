# SDD 导航

1. 读取 docs/sdd/versions.md；恢复唯一 active 或用户明确指定的 draft/finished。没有 active 时可初始化、规划或只读审查。
2. 读取 docs/sdd/steering/ 与 docs/sdd/current/ 的相关章节。
3. 读取 docs/sdd/specs/<version>/version.md，校验 Version、Prefix、Status。
4. 按当前操作读取对应规格与 TASK；只在 Historical dependencies 明确引用时查历史。
5. 遵循项目与用户已有授权；实质范围/业务契约/风险变化才澄清。
6. 默认前期完成后再开下一 version。脚本机械校验通过不能替代真实验收。

本入口只提供导航，保留项目已有规则。
